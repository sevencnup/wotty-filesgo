# FilesGO 主题改造开发文档（第四轮简约化，2026-05-20）

## 需求目标
将首页从“花里胡哨”的强装饰风格收敛为更简约、更统一的视觉效果。

## 评估结论
本轮属于首页主模块样式收敛与节奏重构，需要保留开发文档并按步骤执行。

## 执行步骤
1. 复盘问题：顶部蓝色盖板、悬浮品牌块、强光效和大阴影造成视觉噪音。
2. 保留品牌识别，但缩小 Logo 体量，弱化装饰块背景。
3. 去掉厚重的文件夹盖板效果，改为轻量品牌头 + 纯净主卡片。
4. 下调背景光效、阴影和 tab 装饰强度，保留必要层次。
5. 构建验证并更新版本记录。

## 实施结果
- 首页主题已向简约风格收敛，品牌头与内容区更克制、更统一。
- 主卡片保留层次，但不再依赖大面积装饰和夸张悬浮感。
- `npm run build` 通过。
